# 🔄 Python Text Case Converter

A simple and modern **Text Case Converter** desktop application built with **Python and Tkinter**.

This application allows users to quickly convert text into different letter cases and copy the converted result with ease.

---

## ✨ Features

- 🔠 Convert text to UPPERCASE
- 🔡 Convert text to lowercase
- 🅰️ Convert text to Title Case
- ✍️ Convert text to Sentence Case
- 🔄 Convert text to sWAP cASE
- 📋 Copy converted text
- 🧹 Clear input and result
- 📊 Word count
- 🔢 Character count
- ⚠️ Empty input handling
- 🌙 Clean dark-themed interface
- 💻 Lightweight desktop application
- 🚫 No external packages required

---

## 🛠️ Technologies Used

- Python 3
- Tkinter
